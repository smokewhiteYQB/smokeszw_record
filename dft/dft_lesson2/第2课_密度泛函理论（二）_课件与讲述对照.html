录音：第 1 段（前）课件 4课件 5课件 6课件 7课件 8

先讲原子单位。国际单位制（SI）在量子力学里面会面临比较现实的困难：把氢原子的薛定谔方程写出来，-ħ²/(2m)∇² - e²/(4πε₀r) = Eψ，其中 ħ≈1.054×10⁻³⁴ J·s、电子质量、电子电荷、ε₀ 等常数数值极小、有效数字非常多。这带来两个问题：①推导时每一步都要写冗长的数值（冗余推导），非常复杂，而且数值丢了可能就错了；②数值计算有精度隐患——计算机处理数量级悬殊的数值会引入舍入误差，导致迭代发散或结果失真，推高计算成本；单位换算也会增加很多负担。

科学家的办法是采用原子单位（量子力学原理件）：原子单位（常称 Hartree 原子单位，Hartree 在量子化学中系统推广并应用，其思想建立在 Bohr 等人关于原子尺度自然单位的思想之上）的核心想法是——把电子质量 m_e、元电荷 e、约化普朗克常数 ħ、以及 4πε₀ 通通设为 1。这样氢原子方程就从 -ħ²/(2m)∇² - e²/(4πε₀r) 变成 -½∇² - 1/r：剥离所有物理常数干扰，聚焦能量与相互作用的核心关系，大幅降低理论复杂度。

直观理解：跑步一圈 400 米，跑三圈就是 1200 米；但在原子单位视角下，我们把“一圈”定义为 1，你跑了 3 圈就不用写 3×400，物理效率倍增。原子单位是微观世界的自然语言，让理论推导回归物理本质，已成为量子力学与量子化学通用的标准。

换算：采用 Hartree 原子单位把四个量设为 1 后，凡是公式里遇到长度的单位就是 Bohr（玻尔）：1 Bohr = 0.529 Å = 5.29×10⁻¹¹ m（做纳米相关工作常用 Å）；遇到能量的单位就是 Hartree（哈特里）：1 Hartree = 27.2114 eV；涉及时间有 1 t_AU ≈ 2.4189×10⁻¹⁷ s；速度 ≈ 2.1877×10⁶ m/s。本课程主要讲静态问题，记住长度和能量两个就够了。

也有其他定义方法，例如 Rydberg（里德伯）原子单位：ħ²=1、m=1/2、e²/(4πε₀)=1（前四项定义略有不同），长度单位变为 2 个 Bohr，能量单位 1 Rydberg = ½ Hartree = 13.6057 eV，时间单位 4.83777×10⁻¹⁷ s，速度 1.09385×10⁶ m/s。在 DFT 理论的实际运用中主要用 Hartree 单位。

原子单位除了简化写法，数值计算也会非常稳定：物理量的数值集中于 0~10 之间，恰好落在计算机浮点运算的最佳精度区间，有效规避舍入误差与溢出。主流第一性原理软件（VASP、QE 等）均默认采用原子单位制，保障跨平台计算结果的一致性。

水分子：78 项相互作用

录音：第 1 段（中）课件 13课件 14课件 15课件 16课件 17

看一个稍微复杂一点的例子——水分子。一个水分子有 3 个原子核和 10 个电子，把它的定态薛定谔方程写出来：哈密顿量有五项——两项动能（单体项，每个粒子只与自己有关）+ 三项相互作用（双体项，与两个粒子有关）。

数一数单体项和双体项分别有多少：单体项 = 3（原子核）+ 10（电子）= 13 项；双体项中——核-核两两相互作用 3 项（C₃²）、电子-核相互作用 3×10 = 30 项（每个电子都可以与每个原子核有库仑作用）、电子-电子相互作用 C₁₀² = 45 项。一个氢原子方程只有 2 项，而一个水分子（才 3 个原子）哈密顿量已经变成了 78 项——复杂度急剧上升。

思考：一个水分子 78 项，两个水分子有多少项？26 个粒子，相互作用 C₂₆² = 325 项，是 78 项的 4.166 倍。真实世界远比水分子复杂——尽管能把多体体系的哈密顿量写出来，但相互作用项特别多，精确求解这样的薛定谔方程是不可能的。物理学的思想起作用了：先近似、再近似（所以 DFT 也有人叫 DFA——Density Functional Approximation，密度泛函近似）。

绝热近似是否一定成立？成立必须满足三个物理条件：①核运动足够慢，电子态有时间跟随核坐标变化；②能级间隔足够大，避免相邻电子态之间发生跃迁；③远离交叉且耦合弱，非绝热耦合项相对能隙足够小。能级演化图中：慢变时跟随同一条势能面；能级近交叉时发生跃迁、概率上升；强耦合区对应绝热面（避免交叉）与透热面（虚线）的差别。

有了期望值的形式，下一步怎么求？需要用变分法（对泛函求极值、推导最优化函数条件，最终得到单电子的运动方程）。变分近似法：自然界中广泛碰到有相互作用的多粒子体系，例如研究分子、原子、原子核和粒子结构，研究固体中电子运动以及电子与晶格的相互作用——与经典力学中的情况相似，有相互作用的多粒子体系很难严格求解，实际上不能严格求解，而只能近似处理。这里包含两个含义：一是采用适当的模型把物理问题简化；二是即使对已简化模型，往往也只能用近似计算方法求解——这些近似方法中用得最广泛的是微扰论和变分法。

变分原理（曾谨言《量子力学》）：设体系的能量平均值表示为 H̄ = ∫ψ*Hψdr，则体系的能量本征值及本征函数，可以在条件（归一化）下让 H̄ 取极值而得到，即 δH̄ - λδ∫ψ*ψdr = 0，λ 为 Lagrange 乘子。

历史上有名的变分问题——最速降线问题（Johann Bernoulli 提出，Leibniz、Newton、Jacob Bernoulli 完成）：小球从斜坡上下到 B 点，哪一条路最快？可以有不同的走法。这里只有势能转换为动能：mgy = ½mv²，v = √(2gy)；ds = √(2gy)dt，ds = √(1+(dy/dx)²)dx，总时间 T = ∫₀ˣ¹√(1+(dy/dx)²)/√(2gy) dx。选择不同曲线，时间完全不同；最优的路径不是直线，而是某一条曲线（摆线）。关键：自变量是一个函数 y(x)，对不同的 y(x) 时间 T 不同——T 是 y(x) 的泛函。这就有点像 DFT 里“密度是坐标的函数、总能量是密度的泛函”。

函数 vs 泛函：函数的定义——变量 x 区域中每一个 x 都对应一个 y 值，则称变量 y 是变量 x 的函数 y=y(x)；泛函的定义——对于某一类函数 y(x) 中每一个 y(x) 都对应一个 Π 值，则称变量 Π 是变量 y(x) 的泛函 Π=Π(y(x))。连续性：x 的微小改变对应 y(x) 的微小改变，则函数连续；y(x) 的微量改变对应泛函的微量改变，则泛函连续。所以说泛函其实是一种广义的函数。

微分 vs 变分：函数的宗量 x 的增量 Δx 是指两值之差（Δx = x-x₁），x 的微分用 dx 表示，dx 也是增量的一种，增量很小时 dx = Δx；泛函 Π(y(x)) 的宗量 y(x) 的增量很小时称为变分，用 δy(x) 或 δy 表示，δy(x) = y(x)-y₁(x)——δy(x) 也是 x 的函数，只是在指定的 x 区域中都是微量。函数的微分与泛函的变分可以类比。

有了 Hartree 方程怎么求解？需要用到自洽迭代的过程：方程里的波函数是未知的（很复杂，确实求解不出来），先猜测一组初始波函数 φᵢ⁰；由初始波函数计算库仑项 ĝᵢ(r) = ∫dr'|φⱼ(r')|²/|r-r'|；再求解方程 (T̂ᵢ+v̂ᵢ+ĝᵢ)φᵢ = εᵢφᵢ 得到新的波函数；比较新波函数与初始波函数是否收敛（|φᵢ-φᵢ⁰| < 阈值）：收敛则输出结果、进一步计算想要的性质；不收敛则把新波函数当作下一步的猜测波函数，重新计算 ĝᵢ、再求解方程——一直循环，直到差值小于一定值就认为收敛。

自洽迭代法是通过迭代方法逐次逼近：①构造相应的迭代公式；②选取方程的初始近似根 x₀；③代入迭代公式反复校正根的近似值。例如求方程 f(x) = x³-x-1 = 0 的根：先把问题改写成等价迭代公式 x = g(x) = ∛(x+1)；取初始近似根 x₀ = 1.5；代入得 x₁ = g(x₀) = ∛(1.5+1) = 1.35721；由于 |x₀-x₁| > 10⁻⁴，继续迭代：x₂ = ∛(x₁+1) = 1.33086、x₃ = 1.32588、x₄ = 1.32494……迭代 8 步收敛到 1.32472——一步步循环，最后数值稳定下来，这就是想要的值。

真实情况下的自洽求解会更复杂，还会用到不同的混合方法：自洽求解就是从一个初始猜测 ρ₀ 出发，循环求解得到 ρ₁、ρ₂……最终需要 ρ_{n+1} ≈ ρ_n 收敛，找到方程的解。因为物理系统非常复杂，直接迭代很难找到解，所以需要混合方法——把每次迭代计算得到的 ρ_n 按一定算法进行加权平均，得到新的猜测值进行下一步迭代。常用的混合方法有 Linear、Pulay、Broyden 等。

Hartree 求解总结与缺点

录音：第 3 段（末）课件 56课件 57

总结 Hartree 近似的求解过程（5 步）：①利用单电子波函数的乘积作为变分波函数——简化问题：真实多体波函数难以求解，假设电子独立运动（乘积形式）是最基础的近似，将复杂的多体问题大幅降维；②计算体系总能量的平均值——建立目标：根据变分原理，最接近真实的物理态是系统能量最低的态，必须先算出总能量表达式，才能去寻找这个最低点；③构造一个总能量附加波函数归一化条件的泛函——守恒约束：电子不能凭空消失，利用拉格朗日乘数法引入归一化条件，强制保证在能量求极小的过程中，单个电子的概率分布总和始终为 1；④对泛函取变分极小得到有效势的单电子方程——寻找最优解：对泛函求导找极小值，推导出最优波函数需满足的条件，即单个电子在其他电子形成的“平均势场”中运动的单体方程；⑤对单电子方程自洽求解——解开循环依赖：势场怎么分布取决于波函数，波函数怎么变化又取决于势场，只能“先猜一个势场算波函数，再用新波函数算新势场”，不断循环迭代直到结果不再改变。后面要讲的 Hartree-Fock 近似、KS 理论求解过程都是类似的。

Hartree 近似有两大缺点：①在 Hartree 近似中，多电子的本征波函数是单电子本征波函数的乘积，这种近似没有考虑电子是费米子、需要满足泡利不相容原理——泡利不相容原理体现在两个方面：两个电子不能处于相同的电子态；两个电子进行交换，波函数需要变号。②Hartree 近似采用平均场理论，没有考虑电子的关联相互作用。下一节课讲 Hartree-Fock：Fock 的方法会解决泡利不相容（电子交换反对称性），但电子关联问题依然不能完全解决——这就是后面要讲的内容。
