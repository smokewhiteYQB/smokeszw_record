复习：连续时间流模型、连续性方程与速度场

录音：前半（课首复习）课件 1课件 2课件 3

上半节课先把流模型这一块讲完。正式进入新内容之前，先把上节课的东西复习一遍：我们通过 ODE 的方式做了一个连续时间的流模型，它用最优传输（OT）的思路，让样本沿着一条比较“匀速”的路径从噪声走到数据。对这样的模型，给定采样得到的纯噪声，对速度做积分就能得到任意时刻噪声的样子；我们还通过连续性方程推出了概率密度随时间演化的方程，把符号明确了一下。

有了这个描述，就可以做积分，从某个时刻算出任意时刻样本的对数似然，进而得到 T=1（干净样本）时的似然，再用最大似然去训练。但上节课也说过，这种做法计算成本非常高：给定 x1 之后要不断求解 ODE，才能得到对应的 x0，再积分回 x1，整条 ODE 路径的开销很大。

解决办法是注意到积分项里都有同一个速度 v，这跟 Score-based Model 的想法类似：模型不去直接建模概率密度或数据分布，而是建模这个速度场。得到速度场之后，仍然可以通过积分采样、算出任意时刻的量，最终的学习目标就是用含参模型 v_θ 去拟合真实的边际速度 u_t。但这里留下一个问题：作为监督信号的真实速度其实是不知道的，怎么把学习目标转化成可求解的目标，就是接下来要推导的内容。

课件把两种连续时间模型并排放在一起：Flow Model 从 x0~p0 出发，动力学是 ODE dx_t = v_θ(x_t,t)dt；Diffusion/Score-based Model 从 x_T~p_prior 出发，动力学是 Score SDE，反向过程里多一个 score 项。两者的共同点是：采样就是从一个简单先验出发，模拟 ODE 或 SDE 到数据分布。

两组概念：Conditional 与 Marginal 的概率路径和速度场

录音：前半（概念与可视化）课件 4

在推导之前，先介绍流模型里三组重要概念，每一组都有 Marginal 和 Conditional 两个版本。第一是概率路径（Probability Path）：它描述数据分布在 t 从0到1的演化过程，p_t(x) 是 Marginal 形式；给定某个终点 x1 之后的演化路径 p_t(x|x1)，是 Conditional 形式。第二是对应的速度场：u_t(x) 是 Marginal 速度场，u_t(x|x1) 是给定 x1 的条件速度场。第三是学习目标（loss），同样有 marginal 和 conditional 两个版本。

为什么要定义这两套？因为直接学边际的东西太难，而条件的东西是可控的。给定终点 x1，从高斯分布到这一个点的传输路径可以定义成一条高斯路径，对应的速度场是解析可写的；而不给定 x1、只看整个目标分布时，路径会复杂得多——比如目标是二维平面上的棋盘分布，从高斯出发的边际概率路径会经历复杂的演化，最后才收敛到棋盘形状。同样是从 p0 出发、同样的生成过程，给定与不给定 x1，定义的路径完全不同。

课上放了网站上的可视化：左边是条件概率路径，任意时刻都是一个分布（用采样点表示），从充满空间的高斯不断聚集到目标点；背景里的小箭头就是速度场，每个位置、每个时刻都有各自的速度，随 t 不断变化。右边是边际概率路径，不再指定终点，而是从高斯传输到整个目标分布，最终接近目标分布的形状。掌握这两个量，才能建立直观认识。

条件速度匹配：线性插值的朴素设计

录音：前半（CFM 构造）课件 5

最直接的做法是条件速度匹配（Conditional Velocity Matching）：把高斯分布变换到一个数据点，用线性插值构造路径。第一步采样两个端点，x0 从标准高斯采样、x1 从数据分布采样；第二步构造路径 x_t = t x1 + (1−t) x0，t 服从0到1的均匀分布；第三步写目标条件速度，对路径求导就是 u_t(x_t|x1) = x1 − x0，是个常数向量；第四步就是学习目标，让模型 v_θ(x_t,t) 去拟合 x1 − x0，写成均方误差 ℒ_CFM。

这个路径之所以简单，是因为它是直线：从噪声点到数据点的连线，方向固定、速度恒定，不需要解任何隐式的概率路径。课上强调，你也可以构造其他路径，但线性插值最简单，也最容易把目标算出来。这就把“拟合未知的真实速度”变成了“拟合一个能解析写出的条件速度”。

朴素 DDPM 为什么慢：1000 步与不能跳步

录音：后半（采样加速·问题）课件 12课件 13课件 14课件 15

先说问题：朴素 DDPM 采样极慢。生成一张图要 T=1000 步，步数一减少质量就严重下降；高分辨率、视频生成很难 scale，实时应用更不可能。为什么会这样？因为训练时 T 必须足够大，每一步加的噪声才足够小，对应的后验分布才近似高斯，扩散模型的训练（反向也按高斯采样）才成立。

看直观图：采样就是不断地从 p_θ(x_{t−1}|x_t) = N(x_{t−1}; μ_θ(x_t,t), σ_t²I) 里取一个点。均值 μ_θ 可以写成 score 与噪声预测的关系：s_θ(x_t,t) = −ε_θ(x_t,t)/√(1−ᾱ_t)，而 score 又近似等于 ∇ log q_t(x_t)。所以每一步本质上就是“用模型预测的噪声，把当前点往数据分布的方向推一点，再加一点方差”。

问题在于，反向采样只定义了 x_t 与 x_{t−1} 相邻两步之间的关系。想跳过若干步，公式上并没有直接的办法——这就是“没法把算法分解、让生成实时化”的根本原因。

另一种去噪目标：先重建 x0，再确定性跳步

录音：后半（DDIM 直观推导）课件 16课件 17课件 18课件 19课件 20

换一个去噪目标就能跳步。前向过程有两个关系：逐步加噪 x_t = √(α_t) x_{t−1} + √(1−α_t) ε，以及一步到位 x_t = √(ᾱ_t) x0 + √(1−ᾱ_t) ε。既然 DDPM 学的是 ε_θ(x_t,t)，就可以反解出干净数据的估计：x0|t ≈ (x_t − √(1−ᾱ_t) ε_θ(x_t,t))/√(ᾱ_t)。

有了 x0|t，再代回一步加噪的公式，就得到 x_{t−1} 的确定性估计：x_{t−1} ≈ √(ᾱ_{t−1}) x0|t + √(1−ᾱ_{t−1}) ε_θ(x_t,t)——注意这里复用了同一个噪声预测，没有重新采样随机噪声，所以是确定性的。形式上它跟加噪一步几乎一样，只是噪声是从当前点估计出来的。

关键的一步：既然 x0|t 已经估出来了，为什么还要经过 x_{t−1}？可以直接算 x_{t−2} = √(ᾱ_{t−2}) x0|t + √(1−ᾱ_{t−2}) ε_θ(x_t,t)，甚至跳更多步。因为 ᾱ 都是预设的噪声调度参数，跳步只需要换系数。每次跳10步，原本1000步就变成100步，10倍加速。这条确定性轨迹就是 DDIM 加速的最基本形式。

把随机性加回来：DDIM

录音：后半（DDIM 与随机性）课件 21课件 22课件 23

纯确定性的跳步有一个副作用：从同一个噪声点出发只能得到同一条轨迹，样本多样性受限。把随机性加回来就得到 DDIM：在确定性估计上加一项 σ_t z，z~N(0,I)，同时把系数调整为 √(1−ᾱ_{t−1}−σ_t²)，保证在目标噪声水平上方差保持（variance-preserving）。

于是采样公式变成 x_{t−1} ≈ √(ᾱ_{t−1}) x0|t + √(1−ᾱ_{t−1}−σ_t²) ε_θ(x_t,t) + σ_t z。σ_t 取0就退化成确定性采样，取特定值就回到 DDPM 的随机采样；介于两者之间，可以连续调节随机性。配上跳步，就是 DDIM。

课件特别说明：这里给的是 DDIM 的直观引入，严格推导要看原文（Song、Meng、Ermon，ICLR 2021）。它的正式理解是去掉马尔可夫链的要求，但保证每个 x_t 在去噪过程中的边缘分布不变——边缘分布不变，就可以复用同一套预训练模型，任意跳时间采样。这个角度比直观推导复杂，但论文写得很好。DDIM 的重要性在于：加速过程不需要重新训练，只在采样阶段改，采样步数就能少很多。

让训练参与加速：蒸馏、渐进蒸馏与一致性模型

录音：后半（训练参与的加速）课件 24课件 25课件 26课件 27

如果不满足于“只改采样”，把训练也加进来，可以进一步减少步数。最直观的是蒸馏：教师是一个训练好、参数量大的多步模型，学生是一个更轻量的小模型；让两者从同一个噪声点出发，学生一步的输出去匹配教师两步之后的输出——学生一步实现两步去噪，参数量还更小。

在此之上做 progressive distillation：再引入一个新的学生，让它的一步去匹配上一个学生两步的结果，逐级把步数减半。为什么不直接从噪声一步到位？因为时间隔得越久，中间变化越复杂、非线性越强；逐级蒸馏每一步的损失更小，训练更稳。

一致性模型（Consistency Model）走得更远：给定预训练扩散模型的 Probability Flow ODE，要求新模型在这条轨迹上任意两点给出相同的预测——也就是把整条 ODE 的终点“提前”学到手，从而可以一步或极少数步生成。它不一定非要通过蒸馏实现，也可以从头训练。

把采样当数学问题：ODE 求解器加速（DPM-Solver）

录音：后半（ODE 求解器）课件 28课件 29

最后一个加速视角：既然扩散模型可以写成 ODE，采样就是一个数学问题，可以用更好的数值求解器。概率流 ODE 里，漂移项 f(x_t,t) 在 DDPM 这类模型里是线性的（与 x 成比例），这部分可以解析求解，不用数值积分；剩下由模型学出来的 score 项，用泰勒展开做局部线性化。这样就把原来复杂的 ODE 变成结构更好、更简单的 ODE，从而用更少的求解器调用达到同样的精度。

DPM-Solver（Lu et al., NeurIPS 2022）就是这么做的，号称十步左右就能出好结果。课件用两张图对比：横轴是 NFE（每个样本调用网络的次数），纵轴是 FID（生成质量，越低越好）。固定一个 FID 画横线，新方法在更少的 NFE 下就能达到——同样12次调用，效果明显好于 DDPM 基线；连续时间版本对比 Euler solver 也是同样趋势。这就是“借 ODE 动力学的做法，用经过设计的采样器实现更高级的采样”。

训练设计（一）：噪声水平与信噪比决定任务难度

录音：无（课件页，课上未展开）课件 30课件 31课件 32课件 33

说明：本节内容出现在课件中，但课堂录音在此前已结束（教师说明训练与模型设计留到下次课），以下按课件页面整理，没有原声可对照。

训练过程的第一个设计维度是噪声水平。一步加噪写成 x_t = √(ᾱ_t) x0 + √(1−ᾱ_t) ε，信噪比定义为 SNR(t) = ᾱ_t/(1−ᾱ_t)。它决定了这个时间步上任务有多难：t→0 时噪声很低、SNR 很高，x_t≈x0，预测干净数据很容易、预测噪声很难；t 居中时信号与噪声混合，两个目标都难；t→T 时噪声很高、SNR 很低，x_t≈ε，预测噪声容易、预测干净数据难。

这条“难度随噪声水平变化”的曲线，是后面所有训练设计选择的出发点：参数化选什么、损失怎么加权、噪声调度怎么设，本质上都是在处理这条 SNR 轨迹。

训练设计（二）：x0 与 ε 参数化只是时间步加权不同

录音：无（课件页，课上未展开）课件 34课件 35

把 x_t 写成 a_t x0 + b_t ε（a_t = √(ᾱ_t)，b_t = √(1−ᾱ_t)），两种参数化可以互相换算：给定 x0-预测，ε = (x_t − a_t x0)/b_t；给定 ε-预测，x0 = (x_t − b_t ε)/a_t。相应地，估计误差之间也差一个系数：ε − ε̂ = −(a_t/b_t)(x0 − x̂0)。

把这个系数平方带进损失，就会发现两种学习目标只差一个时间步权重：ℒ_ε = E[‖ε − ε_θ‖²]，ℒ_x0 = E[SNR(t)·‖x0 − x0,θ‖²]。也就是说，用 ε 参数化训练，等价于对 x0 目标按 SNR 加权。选哪种参数化，实际上是在选“哪些噪声水平更重要”。

噪声调度（noise schedule）决定信号 x0 被破坏得多快，也就决定 SNR 轨迹怎么走。课件对比线性调度与余弦调度：余弦调度能比线性调度更久地保留有用信号，在中间噪声段的表现更好。关键认识是：调度应该去塑造 SNR 轨迹，而不只是塑造 ᾱ_t 本身。

更进一步，可以把噪声调度本身当成可学习的目标：把调度参数化，然后对 t~U(0,T)、ε~N(0,I) 最小化扩散损失 ℒ_t 的方差。Variational Diffusion Models（Kingma et al., NeurIPS 2021）就是这么做的，ELBO 可以拆成先验损失、扩散损失、重建损失三部分，调度通过最小化扩散损失的方差来学。

训练设计（四）：重参数化与速度参数化

录音：无（课件页，课上未展开）课件 40课件 41课件 42课件 43课件 44

既然预测 x0 在低噪时容易、预测 ε 在高噪时容易，中间段两者都难，那就预测两者的混合——这是重参数化（re-parameterization）的思路，用同一个网络在不同噪声水平上平衡两种目标。Progressive Distillation 用的就是这个做法。

速度参数化（velocity parameterization）把 x_t 看成干净信号与噪声的混合 x_t = α_t x0 + σ_t ε，其中 α_t² + σ_t² = 1，等价于 x_t = cos φ_t x0 + sin φ_t ε；要预测的是沿这条混合路径的变化方向 v = dx_t/dφ_t = −σ_t x0 + α_t ε。它有两点好处：一是在信号与噪声预测之间取得平衡，二是跨 SNR 更稳定；而且可以由 v 反解 x0 = α_t x_t − σ_t v、ε = σ_t x_t + α_t v，误差关系是 ‖v − v̂‖² = ‖x0 − x̂0‖² + ‖ε − ε̂‖²。现代扩散模型大多用这种参数化。

SNR 还指导其他设计：采样时在更难的噪声级多花步数；条件注入用 σ 或 log σ 而不是原始时间步索引 t（对时间调度不变、连续取值更灵活、log σ 数值尺度更好）；训练时更频繁地采样“有信息量”的噪声级，并按 SNR 加权。

模型设计（一）：设计空间与维度灾难

录音：无（课件页，课上未展开）课件 45课件 46课件 47

模型设计有三个问题：预测什么（μ/ε/x0/v 四种参数化）；在哪里扩散（像素空间还是潜空间）；如何去噪（CNN 还是 Transformer、U-Net 还是 DiT）。这三条构成了模型层面的设计空间。

为什么不能一直在像素空间做？DDPM 在 256×256 的像素空间扩散，去噪网络的输入输出都是同样尺寸的张量；如果想训练 4k 图像，网络要处理的张量尺寸随分辨率平方增长，像素空间扩散的扩展性很差——这就是维度灾难。

模型设计（二）：自编码器与潜空间扩散（LDM）

录音：无（课件页，课上未展开）课件 48课件 49课件 50课件 51课件 52

解决思路是用自编码器压缩：编码器 q_φ 把图像压到潜空间 z0，解码器 p_θ 再重建图像；扩散过程完全在潜空间里做——前向是 z_t = √(ᾱ_t) z0 + √(1−ᾱ_t) ε，反向从 z_T 去噪到 z0，最后解码成图像。这就是 Latent Diffusion Model（Rombach et al., CVPR 2022）。

LDM 的训练分两步：第一步在数据集上预训练自编码器（重建质量要好）；第二步固定自编码器，在对应的潜空间里训练扩散模型。因为潜空间维度远低于像素空间，同样的网络容量可以处理更高分辨率的图像，这也是 Stable Diffusion 这类模型的基础。

模型设计（三）：从 U-Net 到 Diffusion Transformer

录音：无（课件页，课上未展开）课件 53课件 54课件 55课件 56

去噪网络的经典结构是 U-Net：编码器逐级下采样提取多尺度特征，解码器逐级上采样恢复分辨率，同级之间用跳跃连接把细节传过去，从而在输入噪声张量的同时输出同尺寸的噪声预测。U-Net 在图像扩散里长期是主力。

更 scalable 的选择是 Transformer：DiT（Peebles & Xie, ICCV 2023）用 VAE 编码图像、加噪、切分成 token，交给 Transformer 去预测噪声（同时输出后验方差），时间步与类别条件通过 AdaLN 注入。模型越大、token 越多，生成质量越好，这条 scaling law 让扩散模型也能像大语言模型一样“堆规模”。
