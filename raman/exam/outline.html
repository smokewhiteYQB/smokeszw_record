★★★倒格子基矢计算 b₁=2π(a₂×a₃)/[a₁·(a₂×a₃)]（叉乘除以原胞体积），并验证 Bᵢ⊥AⱼL02§06、L10§05

★★布里渊区：定义（倒空间维格纳-赛茨原胞）、简单立方是立方体、FCC 是截角八面体。老师只要"大概了解长什么样"，用它看文献L02§08、L10§02
★★★一维晶格振动：牛顿定律法——①受力分析（第 1 步）②写运动方程（第 2 步）③代格波解求色散L03§05、L10§03

★★★交错力常数双原子链：自行求布里渊区边界（与倒格子计算串联考）L10§09
★★★声子态密度与范霍夫奇点：由色散求 dω/dq；1D 有奇点、2D 台阶状、3D 连续、0D 分立能级L03§12、L10§08
★★二维/三维晶格振动的特征：光学支/声学支数目（3 维 3 声学+3n−3 光学）、q 的取值要求L03§09、L10§03
★对称操作与矩阵表示（旋转、反演、反映）；矩阵作用于介电常数张量→各向同性时退化为标量L01§22、L10§02

2. 第二章 拉曼光谱学介绍（L03–L04）

要求内容出处
★★★横坐标单位换算：ν̃[cm⁻¹]=10⁷/λ[nm]、E[eV]≈1240/λ[nm]、1 cm⁻¹≈1.24×10⁻⁴ eV、Δν̃=10⁷·Δλ/λ²。要会：绝对波数 ⇄ 拉曼位移 ⇄ 波长 ⇄ 能量 互算L03§21、L10§10、L10§14
★★★拉曼光谱的零波数＝入射光能量位置，红外光谱的零波数＝绝对零能量：同一个 521 cm⁻¹ 峰在两者中数值相同、含义完全不同L10§10
★★★瑞利/布里渊/拉曼三者区别；Stokes 与 Anti-Stokes 的频率（ω_L∓ω_q）与波矢（k_L∓q）；AS 强度远小于 Stokes（玻尔兹曼）L03§21、L04、L10§17
★★拉曼散射的发现（海水为什么是蓝的）、线性/非线性散射（受激拉曼、CARS 等）、散射截面定义L03§21
★★拉曼 vs 红外活性判据：拉曼要求 Δα≠0，红外要求 Δμ≠0L06§16
★荧光、吸收、透射、反射等现象与光谱的对应关系L03§21
☆X 射线非弹性散射测声子"建议简单了解即可"；升降算符/量子涨落耗散"了解即可"L04§35、L05§11

3. 第三章 拉曼散射理论基础（L05–L07）

要求内容出处
★★★经典理论：偶极矩 P=αE 展开到一阶，得到 P=P₀+P(ω_L)cos ω_Lt + (α₁E₀/2)[cos(ω_L+ω_q)t+cos(ω_L−ω_q)t]；推出 Stokes/AS 同振幅 → 经典理论无法解释 AS≪S（这是作业题）L05§05、L10§17
★★★量子理论：散射截面表达式与散射概率，"推导是重点"；强度与入射频率四次方、极化率导数、声子占据数（温度）有关L05§01、L05§11、L10§16
★★★拉曼张量：按对称性（不可约表示）查 3×3 张量；**强度 `I∝e_s·R·e_i²`；有多个张量的简并模要平方求和**L07§02、L07§04、L10§18
★★★Porto 记法：z̄(xx)z 四字母＝（散射光传播方向、入射光偏振、散射光偏振、入射光传播方向）；背散射常用 VV/VH/HH/HV；100/010/001 表示 x/y/z 偏振L07§03、L10§18
★★★典型算例（必背）：单层 MoS₂（D3h），E′ 在 VV 可见（I∝d²）、VH 完全消失（I=0）；A₁′ 在 VV、VH 都可见且强度相同（I∝a²）。→ 用 VH 是否消失判断模式对称性L10§18
★★★半波片替代转样品：转 λ/2 波片 θ 角 ≡ 样品转 θ 角，两种配置完全等价；样品不动、可测同一点（微米样品必需）L10§18、L13§02
★★★一阶 vs 二阶拉曼：一阶只涉及 Γ 点声子、峰尖锐；二阶两声子、动量守恒不限 k、是布里渊区积分的连续谱、弱 1–2 个量级；温度依赖：一阶 (n+1)；二阶 Stokes 和频 n₁(n₂+1)、差频 n₂(n₁+1)L10§21
★★五个物理量：峰位、强度、线型、峰宽、偏振特性L06§09
★★AS/S 强度比：I_AS/I_S = [(ω_L+ω_q)/(ω_L−ω_q)]⁴·exp(−ħω_q/k_BT)L06§09
★★拉曼散射不需要考虑相干相加，各分子信号直接相加（与弹性散射/瑞利不同）L06§10
★★电偶极近似：可见光波长 ≫ 分子尺度，e^{ik·r}≈1，忽略空间相位L06§11
☆量子微扰论具体推导"不需要掌握，知道思路即可"；群论特征标表推导"不用管"；SERS/非线性拉曼"只做介绍，非课程重点"L06§13、L06§17、L07§11

4. 第四章 仪器与技术（L08–L11）

要求内容出处
★★★光栅方程 mλ=d(sinα+sinβ)，d=1/(刻线数/mm)；会算给定 λ、α、d 求 βL08§18、L17§03
★★★光谱分辨率：正比于焦长 F × 刻线数 N（课件写 F·N）；提高分辨率 4 条路径：①加长焦长 ②高刻线光栅 ③小像元/多像素探测器 ④选合适波长（高刻线只适用短波）L08§19、L17§03
★★★频率域分辨率 Δν̃=10⁷·Δλ/λ²：分辨"峰位"才需要高分辨，测"强度"不必（高分辨损强度）L17§03
★★★激光线宽：Δλ → Δν̃；总线宽 Γ_total=√(Γ_laser²+Γ_intrinsic²)；瑞利判据：两等高峰可分辨要求峰间距 > 总半高宽。算例：532 nm、Δλ=0.10 nm → 3.53 cm⁻¹，Γ_total=3.67 > 3 → 分辨不了；785 nm → 1.62、1.90 < 3 → 可分辨。结论：做拉曼必须单纵模、窄线宽L17§05
★★★共焦横向分辨率 (0.61λ_ex/NA)/√(1+(λ_ex/λ_det)²) ≈ 0.61λ/(√2·NA)；算例：532 nm、NA 0.9、金刚石 1332 cm⁻¹ → λ_det≈572.6 nm → ≈264 nm；针孔过大时实测退回普通衍射极限L11§02、L17§06
★★★滤光片搭配规则：只测 Stokes → BPF+LEF 或 SEF+LEF；只测 AS → SEF+（BPF 或 LEF）；同时测 S+AS 时谱仪前必须是 BNF（陷波），样品前用 BPFL17§09
★★★最低可测波数：短通片透过率 50% 在 528 nm、532 nm 激发 → 18797−18939 = 142.4 cm⁻¹，测到的是 Anti-Stokes；换 514.5 nm 时截止边不动 → 最低位移 ≈ 754 cm⁻¹；倾斜滤光片可移动截止边（不必按波长换片子）L17§09、L17§10
★★★强度 ∝ ω⁴（λ⁻⁴）：金刚石 1332 cm⁻¹，632 nm 激发散射光 ≈690.1 nm（14491 cm⁻¹），325 nm 激发 ≈339.7 nm（29437 cm⁻¹），I₆₃₂/I₃₂₅=(14491/29437)⁴≈0.06L17§10
★★★平行平板折射位移：sinθ₂=sinθ₁/n，x=t·tanθ₂；3 mm、n=2.08、45°入射 → θ₂≈19.9°、x₂≈1.08 mm vs 空气中 3 mm → Δx≈1.92 mmL17§10
★★提高横向空间分辨率：油镜提高 NA、短波长；突破衍射极限：近场/TERS、STEDL17§04
★★共焦原理（针孔与像点共轭，纵向上作到 ~2 μm、横向 <1 μm，压荧光）；共振拉曼（增强 + 看到弱模，代价是要多种激光）；超低波数两种实现（三光栅加/相减滤波、VBG 布拉格光栅，OD9–12，可测 <10 cm⁻¹，用于剪切/呼吸模）；紫外拉曼（避荧光、共振增强、分辨率高但光路/样品易损）；SERS/TERSL11§01–§06、L17§07、L17§08
★显微拉曼光路：激光→滤光片→物镜→样品→收集→谱仪→CCD；各光学元件的功能与原理L08、L17§01、L17§02
☆光谱仪"计算机部分不讲，重点讲探测器"；激光器"受激吸收和自发辐射不用讲"L08§04、L08§20

5. 第五章 材料物性（L11–L14）

要求内容出处
★★★对称性决定拉曼活性：由点群/不可约表示查张量；多型结构（2H/3R/1T 等）对光谱的影响L11§08、L11§09
★★★层间键极化模型 / 线性链模型：n 层材料有 n−1 个低频层间模（剪切 C 模 + 呼吸 LB 模）；有限层等价一维单原子链＋边界条件，频率解析式 ω_LB(N,N−i)=√2·ω_LB(2,1)·sin(iπ/2N)；算例：双层 40 cm⁻¹ → 5 层取 i=1..4 得 17.5 / 33.3 / 45.8 / 53.8 cm⁻¹（4 个模）；拉曼活性看中心反演：j 偶数时无活性L11§10、L11§12、L17§11
★★★量子限制/受限声子：晶粒越小 → 波矢不确定度大 → 选择定则松弛、M 点（E′(M)、A₁′(M)）二阶峰被激活；峰展宽越大晶粒越小；峰位红移L12§06、L17§13
★★★角分辨偏振拉曼三种配置：①固定散射偏振、转入射偏振 ②转入射+散射偏振（转样品）③共同光路加半波片（样品不动，等效转样品）L13§02、L17§13
★★★温度效应：升温峰位红移（热膨胀＋非谐）；线宽由"电声耦合（降温/低能激发使变窄）"与"非谐衰变（升温变宽）"竞争；石墨（半金属）G 模 FWHM 先降后升 vs MoS₂ A₁′（宽禁带）单调升L13§04、L17§17
★★★应力/应变：单轴应变使简并模劈裂、峰位线性移动（Grüneisen 参数）；双轴应变只移动不劈裂；判据与应变标定L13§05
★★★相变：结构相变/磁性相变/电荷密度波中的模式软化与出现；相变温度附近峰位、线宽的突变L13§01
★★★数据处理：荧光基线扣除（多项式/非对称最小二乘）、峰拟合（Lorentz/Gauss/伪 Voigt）、CCD 随机噪声与宇宙射线剔除、归一化L14§01

要求内容出处
★★★特征峰：G≈1580 cm⁻¹、2D≈2680、D≈1350、2D′、低频 LB/C 模；单层 2D 单洛伦兹、宽≈24 cm⁻¹L14§03、L17§17

7. 六类最可能的题型

  • 单位换算与波长计算：λ→ν̃→Stokes/AS 波长、能量；按荧光位置选激光（L10§14）
  • 结构计算：原胞基矢 → 倒格基矢 → 判定倒格子类型 → 布里渊区形状（L10§05）
  • 晶格振动：受力→运动方程→色散→声学/光学支→态密度/范霍夫奇点（L10§03、§08、§09）
  • 偏振选择定则：给张量算 VV/VH 强度、判断 VH 消失的是哪个模、解释半波片等价性（L10§18）
  • 仪器参数计算：光栅方程、分辨率、共焦横向分辨率、滤光片最低波数、λ⁻⁴、分束器位移（L17§03–§10）
  • 材料谱学判读：石墨烯层数/D 模来源/掺杂/Fano/转角双峰；MoS₂ 呼吸模；温度与应变效应（L17§11–§17）
