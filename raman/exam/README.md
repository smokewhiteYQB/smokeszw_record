# 显微拉曼 · 考场速查台（本地离线）

考试场景专用：**不联网、不依赖任何外部服务**，双击 `index.html` 就能用。

## 打开方式

- 直接双击 `raman/exam/index.html`；
- 或从课程网站首页「显微共焦拉曼光谱学」章节顶部的金色入口进入。

## 它能做什么

| 功能 | 说明 |
| --- | --- |
| 关键词检索 | 顶部搜索框输入题目里的词（中文即可，空格分隔＝同时命中）。覆盖 17 讲 · 286 节讲述 · 922 页课件 · 16 道作业 · 六章作业解答 |
| 页码直达 | 每条结果标注「课件 pX–pY」，点「看课件」直接跳到那几页幻灯片 |
| 整节预览 | 点卡片弹出右侧预览：幻灯片大图 + 老师的原话整理，边看边抄 |
| 课件页直击 | 结果下方的「课件页直击」按页命中，缩略图点开即大图 |
| 作业速查 | 左栏「作业速查」按章列出 16 道作业，附老师讲解与课件页入口 |
| 目录 | 左栏「目录」按 17 讲展开每节，点一下即可预览 |
| 快捷键 | `/` 或 `Ctrl+K` 聚焦搜索；`Esc` 清空/关预览；`↑↓` 选结果，`Enter` 预览，`Ctrl+Enter` 新窗口打开 |

## 检索技巧

- 题目里出现名词，先拆成 2–3 个关键名词再搜，例如「偏振 选择定则」「声子 态密度 范霍夫」「信噪比 积分时间」。
- 整句贴进去也可以：没命中时会自动拆成二字片段做模糊匹配（结果上方会提示拆出了哪些词）。
- 想只看课件图：点顶栏「课件页」；想只看作业：点「作业」；也可用右侧章节下拉限定到某一章。

## 文件结构

```
raman/exam/
├── index.html   页面骨架 + 全部样式（无 CDN、无外链字体）
├── app.js       检索、目录、预览、快捷键逻辑
├── data.js      索引数据（由 _build.mjs 生成，含 922 页课件元数据）
├── _build.mjs   重新生成 data.js 的脚本（需要 node）
└── README.md
```

## 重新生成索引

课程页有改动时，在 `raman/exam/` 下执行：

```bash
node _build.mjs
```

脚本会重新扫描 `../rm_lesson1..17/*.html`，抽取节标题、课件页、讲述文本，并合并 `D:\MyProjects\raman_exam\solutions.json` 里的六章作业解答。
